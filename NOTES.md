# NOTES

The sender receives one 160-byte frame every 20 ms and transmits it immediately as a DATA packet over UDP. Frames are grouped in pairs, and the sender transmits one XOR PARITY packet after every two DATA packets. The resulting 2+1 FEC scheme uses approximately 1.57× measured bandwidth and can recover either missing data frame when the companion frame and parity packet arrive. Each packet carries a sequence number, FEC group number, packet type, and 160-byte payload using a packed wire format with multibyte fields stored in network byte order. The receiver accepts reordered packets, ignores malformed or inconsistent packets, suppresses duplicate delivery with an atomic per-frame flag, and stores per-group state for FEC reconstruction. Original and reconstructed frames are forwarded immediately to maximize deadline margin instead of waiting until their playback deadlines. The implementation does not use retransmission or feedback because both a request and its reply would traverse the impaired relay, making timely recovery unlikely. Profile A achieved a valid run at 60 ms with a 0.67% deadline-miss rate. The recommended grading delay is **110 ms**, which produced 0.80% deadline misses and 1.57× bandwidth overhead on Profile B while providing additional safety margin over the lowest observed valid delay of 100 ms. The design cannot recover when both data packets in the same FEC group are lost, when a data packet and its parity packet are both unavailable, or when the required packets arrive after the playback deadline.

# NOTES

The sender receives one 160-byte frame every 20 ms and transmits it as a DATA packet over UDP. Frames are grouped in pairs, and the sender transmits one XOR PARITY packet after every two DATA packets. The resulting 2+1 scheme uses approximately 1.57x measured bandwidth and can recover either missing data frame when the other data frame and parity packet arrive. Each packet carries a sequence number, FEC group number, packet type, and 160-byte payload using a packed wire structure with multibyte fields in network byte order. The receiver accepts reordered packets, ignores malformed or inconsistent packets, suppresses duplicate delivery with an atomic per-frame flag, and stores group state for FEC reconstruction. Original and reconstructed frames are forwarded to the harness player immediately rather than being held until their deadlines. Immediate forwarding maximizes deadline margin and avoids extra misses caused by scheduler wake-up latency. The implementation uses no retransmission or feedback traffic because a request and reply would both cross the impaired relay and might arrive too late. The recommended grading delay is **120 ms**, which produced 0.80% deadline misses and 1.57x overhead on Profile B. The design breaks when both data packets from the same FEC group are unavailable, when the required parity is lost with a data packet, or when all useful copies arrive after the playback deadline.
